# Evidence Inspector Specification

## Executive Overview

The **Evidence Inspector** is the dedicated transparency panel (Right Pane) of the Creator Research Studio. It provides instant, verifiable provenance for every fact, quote, and hypothesis generated by the AI research assistant.

Every response produced by the assistant is grounded in real, stored feedback records or attached creator documents. Hallucinated or unverifiable citations are stripped by the backend grounding filter before reaching the user.

---

## 1. The Three Evidence Types & Semantic Design Tokens

To prevent confusing user feedback with internal company documentation or AI interpretations, the design system implements **three distinct semantic tokens** with high-contrast text labels:

| Evidence Type | Semantic Color Token | Light Theme HEX | Dark Theme HEX | Text Label & Badge | Key Metadata Displayed |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Community Feedback** | `--evidence-community` | `#0F766E` | `#2DD4BF` | `Community Review Evidence` | Author username/mask, comment ID, quote snippet, jump to comment link |
| **Internal Document** | `--evidence-document` | `#2563EB` | `#60A5FA` | `Internal Document Evidence` | Document filename, genuine page number (or section), chunk ID, full preview link |
| **AI Synthesis** | `--ai-synthesis` | `#7C3AED` | `#A78BFA` | `AI Synthesis & Findings` | Theme title, severity, confidence rating, supporting citation counts |
| **Uncertainty / Gap** | `--state-warning` | `#B45309` | `#FBBF24` | `Data Limitations & Uncertainty` | Evidence gap warning, conflicting feedback notes, sample size cautions |

## 2. Evidence Card Visual Architecture

### A. Community Evidence Card
```
+-------------------------------------------------------------+
| [COMMUNITY REVIEW EVIDENCE]                     #c_9f8a12   |
|                                                             |
| Contributor: @sarah_dev           [Feedback Badge]          |
|                                                             |
| " "The calendar sync latency is unacceptable when syncing   |
|    more than 50 events across timezones." "                 |
|                                                             |
| [ Jump to Comment in Discussion → ]                         |
+-------------------------------------------------------------+
```
- **Author Identity Respect**: If a contributor posted with `isAnonymous=True`, the inspector renders `Anonymous Contributor` with a masked shield icon, strictly preserving contributor privacy.
- **Direct Navigation**: Clicking `Jump to Comment in Discussion` switches the view to the public discussion tab, scrolls smoothly to the target comment DOM node, and briefly highlights it with an indigo pulse.

### B. Internal Document Evidence Card
```
+-------------------------------------------------------------+
| [INTERNAL DOCUMENT EVIDENCE]                        Page 2  |
|                                                             |
| File: quantumdb_whitepaper.pdf                              |
| Chunk: doc_8f1a23_p3                                        |
|                                                             |
| " "Storage layer employs an immutable LSM-tree with         |
|    Byzantine fault tolerance and Raft consensus." "         |
|                                                             |
| [ Open Full Document Preview → ]                            |
+-------------------------------------------------------------+
```
- **Truthful Page Numbers**: If the source is a PDF, the genuine page number is displayed (e.g. `Page 2`). If the source is Markdown, the section header is displayed (e.g. `§ Performance Targets`). No page numbers are fabricated.
- **Deep Inspection**: Clicking `Open Full Document Preview` launches the `DocumentPreviewModal` with complete extracted text and visual page breaks.

### C. AI Synthesis & Uncertainty Card
```
+-------------------------------------------------------------+
| [AI SYNTHESIS & FINDINGS]               Medium Severity     |
|                                                             |
| Theme: Calendar Synchronization Latency                     |
| Grounded in 4 verified community comments                   |
|                                                             |
| ⚠ Data Limitations & Uncertainty:                          |
| Sample size is limited to 4 users; no telemetry data        |
| confirms whether timezone mismatch triggers packet drops.   |
+-------------------------------------------------------------+
```

## 3. Interactive Citation Chip Navigation

In the center conversation stream, assistant messages render clickable citation badges:
- **`[C-1] @contributor`**: Teal citation pill referencing a verified community review.
- **`[D-1] spec.pdf (p.2)`**: Blue citation pill referencing an attached document page.
- **`[S-1] Theme Name`**: Violet citation pill referencing a synthesized cluster.

### Interaction Behaviors
1. **Click to Inspect**: Clicking any citation chip highlights the chip with an active focus ring and instantly populates the Evidence Inspector with that source's complete context.
2. **Auto-Inspection**: Upon receiving a fresh assistant response, the Evidence Inspector automatically populates with the first verified citation, providing immediate grounding without requiring extra clicks.
3. **Session Citations Pool**: Below the active card, the inspector renders a searchable pool of all citations referenced across the current session turns, allowing creators to audit the entire evidence footprint at a glance.

---

## 4. Empty State UX

When no citation is currently active, the Evidence Inspector renders an accessible explanatory empty state:
- Displays a central quotation icon.
- Explains the purpose of the inspector.
- Prompts the creator: *"Click on any citation chip `[C-x]` or `[D-x]` in the conversation to inspect its verified source passage."*
