# 12 — Free Design References, UI Stores and Asset Libraries

This list prioritizes resources with a free browsing tier, free/open-source components or free community assets. **Free to browse does not mean every downloadable asset is free for commercial use.** Check the exact item license, attribution rules, redistribution conditions and account restrictions before using an asset in the product.

## G. Resource evaluation checklist

Before using any reference/asset:
- Is the asset actually free, or only the preview?
- Is commercial use allowed?
- Is attribution required?
- May the asset be modified?
- May source files/components be redistributed?
- Is there a separate Pro license?
- Does the source package use a dependency already in our stack?
- Is the visual pattern accessible and responsive?
- Does it support this product's one-screen/one-goal principle?
- Does it create an avoidable privacy or third-party data dependency?

Record the exact source URL and license in the repository when an asset is adopted.
