# Citation Verification & Evidence Grounding Specification

## 1. Overview
A core requirement of the Product Research Intelligence platform is **zero citation hallucination**. Every observation, claim, or recommendation generated by an LLM must map to an explicit, verified database record.

---

## 2. Citation Format & Semantic Tokens

| Citation Token | Source Type | Visual Style | Example Label |
| :--- | :--- | :--- | :--- |
| `[C-x]` | Community Comment | Teal Badge (`#0F766E` / `#2DD4BF`) | `[C-1] Daniel Thorne` |
| `[D-x]` | Attached Document | Blue Badge (`#2563EB` / `#60A5FA`) | `[D-1] spec.pdf (p.2)` |
| `[A-x]` | Synthesized Theme | Violet Badge (`#7C3AED` / `#A78BFA`) | `[A-1] Usability Theme` |

### Token Rules:
- Numbering is 1-indexed relative to the specific turn or report.
- `[C-x]` badges display the author's public display name (or `"Anonymous Contributor"` if masked).
- `[D-x]` badges display the document filename and page number (`p.X`) or section heading (`§ Section`).

## 3. The 3-Step Verification Pipeline

```mermaid
flowchart LR
    LLM[\\"LLM Output: supporting_comment_ids\\\"] --> Step1[\\"1. DB Map Lookup\\\"]
    Step1 -->|Mismatch / Non-existent| Drop[\\"Pruned (Hallucination Guard)\\\"]
    Step1 -->|Found| Step2[\\"2. Source Ownership Validation\\\"]
    Step2 -->|Unauthorized File| Drop
    Step2 -->|Authorized| Step3[\\"3. Exact Quote Extraction\\\"]
    Step3 --> Persist[\\"Persisted in Message Citations\\\"]
```

1. **Database Map Lookup:**
   Every ID returned in `supporting_comment_ids` is checked against `comment_map`. If the model invents an ID (e.g. `cmt_fake_99`), it is automatically pruned.
2. **Source Ownership Validation:**
   For document chunks, the system confirms that the parent document belongs to the target `postId` and is owned by the authenticated creator.
3. **Exact Quote Extraction:**
   The quote snippet is extracted directly from stored database text (`content[:120] + "..."`), guaranteeing that the snippet presented to the user is 100% authentic verbatim text.

## 4. UI Interaction Model

### Hover & Click Behavior
1. **Citation Badges in Chat:**
   Hovering reveals a tooltip with the verified snippet. Clicking a `[C-x]` or `[D-x]` chip:
   - Immediately focuses the **Evidence Inspector** (Right Pane).
   - Shows the full verbatim excerpt, author attribution, chunk ID, and page/section number.
   - For comments: provides a `"Jump to Comment in Discussion"` button that smoothly scrolls to the public thread.
   - For documents: provides an `"Inspect Document"` button that opens the multi-page preview modal.
2. **Active Selection Highlighting:**
   The clicked citation badge gains a focus ring (`ring-2 ring-indigo-500`) and synchronizes across all open inspector panels.
